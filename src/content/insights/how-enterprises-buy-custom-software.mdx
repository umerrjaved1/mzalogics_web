Enterprise software fails in the handoff, not the demo. If you cannot name the system of record, the identity model, and the person who will run it on Monday, you do not have a plan.

## Write the problem, not the feature list

Ask vendors to restate the operational problem in one page. If they jump to a stack, they are selling capacity, not a system.

## Demand a weekly artefact

A shared board, a living spec, and working software every week. Slideware is not progress.

## Integrations are a workstream

ERP, SSO, and data contracts need owners. Treat them as a stage, not a week-six surprise.

## Leave with runbooks

If the team that built it cannot explain how to operate it, you bought a project, not a product.
